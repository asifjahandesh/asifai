# ASIF AI Microsoft Excel Desktop Add-in (Phase 1)

Professional AI intelligence task pane for Microsoft Excel Desktop on Windows, powered by the ASIF AI Next.js backend and Gridex Smart.

---

## 1. Overview & Architecture

The ASIF AI Excel Add-in is integrated directly into the existing repository without interfering with the ASIF AI web application.

```text
asif-ai/
├── app/
│   ├── api/
│   │   ├── chat/          # Existing Supabase & Gridex chat API
│   │   └── excel/         # Secure Excel-optimized API route with formula parsing
│   ├── globals.css
│   ├── layout.tsx
│   └── page.tsx
├── excel-addin/
│   ├── assets/            # Add-in icons (PNG & SVG)
│   ├── src/               # Task pane UI & Office.js controller logic
│   │   ├── commands.html  # Ribbon commands handler
│   │   ├── taskpane.html  # Excel Task Pane HTML structure
│   │   ├── taskpane.css   # Cyberpunk dark theme with neon-green accents
│   │   └── taskpane.js    # Excel JavaScript API (Office.js) integration
│   ├── manifest.xml       # Office Add-in manifest configuration
│   ├── package.json       # Manifest validation & debugging scripts
│   └── README.md          # Setup & sideloading instructions
└── public/
    └── excel-addin/       # Static assets served via Next.js for local development
```

## 2. Features

- **Ribbon Commands**: Adds a dedicated **ASIF AI** ribbon tab in Excel with:
  - **Open ASIF AI**: Opens the intelligence task pane.
  - **Analyze Selection**: Inspects cell ranges and sends data to Gridex Smart.
  - **Explain Formula**: Explains active cell formulas in understandable language.
- **Office.js Excel Integration**:
  - **Read Selection**: Detects active worksheet name, range address, row/column counts, cell matrices, headers, and formulas.
  - **Analyze Selection**: Formats data into a structured context payload with payload size safeguards.
  - **Explain Formula**: Inspects existing formulas and breaks down functions.
  - **Insert Formula**: Automatically extracts formulas generated by AI (`[FORMULA]=...[/FORMULA]`), displays an approval card, prompts for confirmation before overwriting existing cell values, and writes formulas directly into the selected Excel cell.
- **Cyberpunk Dark Theme**: Matches the official ASIF AI web aesthetic with dark surfaces, neon-green borders, and glowing status tags.

## 3. Local Development & HTTPS Setup

Office Add-ins require HTTPS when running in Excel Desktop.

### Step 1: Ensure Next.js is running

In the root repository directory:
```powershell
npm run dev
```

### Step 2: Configure HTTPS for Localhost

Next.js provides built-in experimental HTTPS support, or you can use `office-addin-dev-certs`:

```powershell
npx office-addin-dev-certs install
```

Start the Next.js development server on HTTPS port 3001:
```powershell
npx next dev --experimental-https --port 3001
```

## 4. How to Sideload into Microsoft Excel Desktop on Windows

Microsoft provides a built-in shared folder sideloading method for Windows Excel Desktop.

### Step 1: Create a Shared Folder on Windows

1. In PowerShell, create a dedicated manifest folder:
   ```powershell
   New-Item -ItemType Directory -Path "$HOME\OfficeAddinManifests" -Force
   Copy-Item "d:\Projects\asif-ai\excel-addin\manifest.xml" -Destination "$HOME\OfficeAddinManifests\"
   ```

2. Share the folder:
   - Right-click `$HOME\OfficeAddinManifests` in File Explorer -> **Properties** -> **Sharing** -> **Share...**
   - Add yourself or `Everyone` with Read permissions and click **Share**.
   - Note the network path (e.g., `\\YOUR-PC\OfficeAddinManifests`).

### Step 2: Trust the Shared Catalog in Excel

1. Open **Microsoft Excel**.
2. Click **File** -> **Options** -> **Trust Center** -> **Trust Center Settings...** -> **Trusted Add-in Catalogs**.
3. Under **Catalog URL**, enter your shared folder path (e.g., `\\YOUR-PC\OfficeAddinManifests`).
4. Check **Show in Menu**, then click **Add Catalog**.
5. Click **OK** and restart Excel.

### Step 3: Insert the ASIF AI Add-in

1. Open a new Excel workbook.
2. Go to the **Insert** tab -> click **My Add-ins** (or **Get Add-ins** -> **SHARED FOLDER**).
3. Select **ASIF AI** and click **Add**.
4. The **ASIF AI** ribbon tab will appear with the three commands.
5. Click **Open ASIF AI** to load the task pane.

## 5. Security & Backend Guardrails

- **Zero Exposure**: `GRIDEX_API_KEY` and Supabase Service Role keys are **never** bundled or exposed to Excel frontend client scripts.
- **Secure Route**: All requests flow through `POST /api/excel` on the Next.js server.
- **Formula Safety**: Confirmation prompt ensures existing cell values are never overwritten without explicit user authorization.
